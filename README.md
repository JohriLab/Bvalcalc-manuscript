The following files in this directory have code to reproduce the B-value calculator (Bvalcalc) manuscript results:

The code used to generate Figure 2 and supplementary figures is available at: Figure2.rmd.

The code used to generate Figure 3 is available at: Figure3.py.

See Bvalcalc_code.sh for a full list of Bvalcalc commands used to generate results, including Figure 4 and the B-maps.

SLiM code for simulations is available at: slimfiles/.

Code used to compare B-maps to empirical data is available at: Bmap_comparison/.

B-value maps across autosomes that we have calculated using template parameters are available for download at Zenodo: https://doi.org/10.5281/zenodo.17334918.

Bvalcalc is available at: https://github.com/JohriLab/Bvalcalc/tree/main/manuscript
Bvalcalc v1.4.3 was used to generate manuscript results.
